# ThumbCAD

**ThumbCAD** is a lightweight, browser-based 3D sandbox designed for fast, approachable creation — no installs, no build steps, no friction.

It runs entirely in the browser using modern WebGL and Three.js, favoring clarity, immediacy, and playful experimentation over complexity.

Think of it as a **3D sketchbook**, not a full DCC suite.

---

## ✨ Why ThumbCAD?

3D tools are powerful — but they’re often intimidating, heavyweight, or locked behind steep setup costs.

ThumbCAD exists to lower that barrier.

**Goals:**

* Make 3D feel *approachable*
* Teach spatial concepts through interaction
* Stay hackable and readable
* Run anywhere you can upload files

If you can host a static site, you can run ThumbCAD.

---

## 🧠 Philosophy

ThumbCAD is intentionally opinionated:

* **No installs**
* **No accounts**
* **No frameworks**
* **No build pipeline**
* **No backend**

Just files you can upload, open, and explore.

Approachability comes first. Power comes second.

---

## 🚀 Features

* Browser-based 3D workspace (Three.js)
* Primitive-based modeling
* Visual gizmos (move / rotate / scale)
* Camera controls for exploration
* Scene persistence via JSON
* Modular, readable codebase
* CDN-based dependencies
* Designed for learning, demos, and rapid prototyping

This first public release prioritizes **stability and clarity** over feature sprawl.

---

## 🧰 Tech Stack

* JavaScript (ES Modules)
* Three.js (via CDN / import maps)
* WebGL
* HTML / CSS
* Zero build tools
* Zero backend requirements

Upload-and-go by design.

---

## 🧑‍🎓 Who Is This For?

* Beginners learning 3D concepts
* Educators teaching spatial thinking
* Designers sketching ideas in 3D
* Developers who want a clean 3D foundation
* Kids (and adults) who just want to make stuff

ThumbCAD is **not** a Blender replacement.
It’s a place to start.

---

## 🛠️ Getting Started

1. Clone or download the repository
2. Upload the files to any static host (or open locally)
3. Open `index.html` in a modern browser
4. Start building

That’s it.

No installs. No config. No setup ceremony.
